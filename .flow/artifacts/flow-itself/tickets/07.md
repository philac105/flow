## What to build
`flow board` writes a single self-contained HTML file (default `.flow/board.html`,
`-o` to override) rendering the Runs as a card grid — one card per Run, showing
title, kind, the Stage sequence with the current position marked, and any Drift.

No external assets, no network, no template engine: substitution into a template
embedded with `include_str!`. It must be legible in both light and dark browser
themes, since it is opened directly from disk with no session running.

## Acceptance criteria
- [ ] `flow board` writes an HTML file that opens standalone in a browser
- [ ] The file contains no external URLs — no CDN, font, image or script host
- [ ] One card per Run showing title, kind and all Stages with current marked
- [ ] Drift is visible on the card
- [ ] `-o <path>` overrides the destination
- [ ] Run titles are HTML-escaped
- [ ] Colours are defined for both light and dark themes
