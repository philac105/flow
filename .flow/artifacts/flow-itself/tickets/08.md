## What to build
`flow init` also writes the Adapter: `.claude/skills/flow/SKILL.md` teaching an
agent the protocol (run `flow next`, do what it says, run `flow done -m` with a
Handoff), plus a delimited `flow` block in `AGENTS.md` saying the same thing for
agents that read that file instead.

Both writes are additive and idempotent (ADR-0004): the `AGENTS.md` block is
updated in place between its markers and never appended twice, and surrounding
content is preserved byte for byte.

## Acceptance criteria
- [ ] `flow init` writes `.claude/skills/flow/SKILL.md` with valid frontmatter
- [ ] `flow init` adds a delimited `flow` block to `AGENTS.md`
- [ ] `AGENTS.md` is created if absent, appended to if present
- [ ] Re-running init updates the block in place — exactly one block, always
- [ ] Content outside the markers is byte-identical after re-running init
- [ ] The Adapter documents the real command surface built in tickets 02–06
