## What to build
Artifact evidence and Drift. Each Stage declares an `artifact` path template
(accepting `{slug}`) or a `tracker:` reference. `flow done --artifact <path>`
records what was actually produced. Flow then compares each Stage's recorded
status against whether its Artifact exists on disk, and reports the
disagreement — a pending Stage whose Artifact exists, or a done Stage whose
Artifact has vanished.

Drift is surfaced in `flow status`, `flow show` and `flow next`. Flow reports it
and never silently resolves it (ADR-0002). This is what makes a session that
died mid-Stage recoverable from disk alone.

## Acceptance criteria
- [ ] A Stage's `artifact` template resolves `{slug}` against the Run
- [ ] `flow done --artifact <path>` records the path on the Stage record
- [ ] A pending Stage whose Artifact exists is reported as Drift
- [ ] A done Stage whose Artifact is missing is reported as Drift
- [ ] Drift appears in `status`, `show` and `next` output
- [ ] Drift is never auto-corrected — the recorded status is left as it was
- [ ] `tracker:` artifacts are not checked against the filesystem
