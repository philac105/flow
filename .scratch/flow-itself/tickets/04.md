## What to build
`flow status` prints the board: every Run in `.flow/runs/`, one row each, showing
slug, kind, current Stage, and progress through the Flow. Finished Runs are
excluded by default and shown with `--all`.

This is the "where is everything" view — the thing typed on a Monday morning.

## Acceptance criteria
- [ ] `flow status` lists every Run with its current Stage
- [ ] Runs are ordered most-recently-updated first
- [ ] Progress through the Flow is visible per Run (e.g. `3/5`)
- [ ] `flow status` in a repo with no Runs prints a helpful empty state, exits 0
- [ ] Finished Runs are hidden by default and shown by `--all`
- [ ] Output stays aligned when slugs and Stage names vary in width
